# 🧱 Manifiesto de Memoria Cognitiva

## Objetivo

La memoria existe para **ayudar a pensar**, no para almacenar todo.

## Tipos de Memoria

### 1. Memoria Temporal
- Conversaciones transitorias
- Ideas en borrador
- Contexto momentáneo

Puede descartarse sin riesgo.

### 2. Memoria Ejecutiva
- Decisiones
- Problemas recurrentes
- Estados de proyectos
- Bloqueos importantes

Debe preservarse mientras el proyecto esté activo.

### 3. Memoria Estructural
- Principios
- Estrategias
- Marcos de decisión
- Modelos mentales

Es estable y de largo plazo.

## Qué NO se guarda

- Mensajes triviales
- Confirmaciones vacías
- Ruido operativo sin contexto

## Regla de Memoria

Más memoria ≠ más inteligencia.  
La memoria debe ser **curada**, no acumulada.
