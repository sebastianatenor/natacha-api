# Manifest 55 — Autonomy Escalation Protocol

## Propósito
Definir cómo escalar autonomía de forma segura.

## Requisitos para escalar
- Historial estable
- Baja tasa de error
- Confirmaciones humanas previas
- Dominio bien delimitado

## Proceso
1. Solicitud explícita
2. Evaluación de riesgo
3. Periodo de prueba
4. Revisión humana
5. Aprobación o rollback

## Regla de Oro
Escalar lento, revertir rápido.
