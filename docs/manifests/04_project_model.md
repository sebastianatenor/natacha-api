# 🧩 Manifiesto de Proyectos

## Realidad del Holding

Sebastián opera un holding dinámico de actividades:
- LLVC
- Made in Latam
- E-commerce
- Proyectos personales
- Oportunidades emergentes

## Principios de Proyecto

- Los proyectos nacen incompletos
- Cambian con el tiempo
- Pueden pausarse y retomarse
- No todos escalan
- No todos deben sobrevivir

## Rol del Agente

Natacha ayuda a:
- Mantener contexto por proyecto
- Separar prioridades
- Evitar contaminación entre proyectos
- Detectar dependencias ocultas

## Regla Clave

Un proyecto no definido no es un problema.
Es una etapa.
