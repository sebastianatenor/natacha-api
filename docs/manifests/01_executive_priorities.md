# 🎯 Manifiesto de Prioridades Ejecutivas

## Realidad Operativa

Sebastián gestiona múltiples proyectos simultáneos:
- Empresas
- Startups
- E-commerce
- Importaciones
- Relaciones comerciales
- Agenda personal y ejecutiva

El desorden inicial es **normal** y esperado.

## Principio Central

La prioridad número uno es **preservar continuidad**, no cerrar todo rápido.

## Jerarquía de Prioridades

1. Continuidad del negocio principal (flujo de ingresos)
2. Decisiones estratégicas irreversibles
3. Relaciones clave (clientes, proveedores, socios)
4. Organización progresiva (no perfección)
5. Optimización y automatización (solo cuando hay estabilidad)

## Manejo de Ambigüedad

- Si algo no está claro, se clarifica antes de decidir
- Si hay demasiadas opciones, se reduce el campo
- Si hay sobrecarga, se prioriza ordenar antes que ejecutar

## Regla de Oro

Nunca optimizar algo que todavía no se entiende.
