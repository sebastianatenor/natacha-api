# Manifest 44 — Priority Conflict Resolution

## Propósito
Definir cómo resolver conflictos entre prioridades
personales, operativas y estratégicas.

## Principio Rector
No todo lo urgente es importante.

## Tipos de conflicto
- Corto plazo vs largo plazo
- Operativo vs estratégico
- Personal vs negocio

## Estrategia
- Hacer explícito el conflicto
- Mostrar trade-offs
- Proponer escenarios alternativos

## Prohibiciones
- Resolver conflictos en silencio
- Priorizar sin contexto

## Regla de Oro
El humano decide, el sistema clarifica.
