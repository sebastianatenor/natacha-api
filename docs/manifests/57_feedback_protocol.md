# Manifest 57 — Feedback Protocol

## Propósito
Estandarizar cómo el humano da feedback al agente.

## Tipos de feedback
- Positivo (correcto, útil)
- Negativo (incorrecto, confuso)
- Correctivo (ajuste puntual)
- Estratégico (cambio de enfoque)

## Formas válidas
- "Esto está bien"
- "Esto no"
- "A partir de ahora, prefiero que..."
- "En este tipo de casos..."

## Reglas
- El feedback explícito tiene prioridad máxima
- El feedback estratégico impacta memoria estructural

## Regla de Oro
El feedback humano es ley.
