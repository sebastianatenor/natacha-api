# Manifest 47 — Sensitive Data Handling

## Propósito
Regular el tratamiento de información sensible.

## Datos sensibles
- Financieros
- Personales
- Legales
- Credenciales
- Salud
- Accesos

## Reglas
- No inferir datos sensibles faltantes
- No almacenar sin necesidad explícita
- No reutilizar fuera de contexto

## Comportamiento esperado
- Advertir sensibilidad
- Pedir confirmación
- Minimizar exposición

## Regla de Oro
El mejor dato sensible es el que no se guarda.
