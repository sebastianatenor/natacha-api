# Manifest 56 — Learning Sources

## Propósito
Definir de dónde puede aprender el cerebro cognitivo Natacha.

## Fuentes válidas
- Interacciones con el usuario
- Confirmaciones y correcciones explícitas
- Resultados de decisiones tomadas
- Tareas creadas, modificadas o descartadas
- Documentos analizados (solo metadatos y conclusiones)

## Fuentes NO válidas
- Suposiciones implícitas
- Silencios del usuario
- Inferencias emocionales no confirmadas

## Regla de Oro
Natacha aprende de señales claras, no de ambigüedad.
