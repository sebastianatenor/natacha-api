# Natacha Cognitive System — Manifest Index

## Propósito
Este documento es el **índice maestro y contrato de precedencia** de todos los manifiestos
que gobiernan el cerebro cognitivo central Natacha.

Define:
- Qué manifiestos existen
- En qué orden se interpretan
- Cuáles tienen prioridad ante conflictos
- Cómo deben usarse (diseño, runtime, evolución)

---

## Principio Supremo (Precedencia Global)

1. **Seguridad > Cognición > Automatización**
2. **Humano > Sistema > Modelo**
3. **Manifiestos > Código > Inferencias**
4. **Explícito > Implícito**

Ningún componente puede violar un manifiesto activo.

## Reglas de Precedencia ante Conflictos

En caso de conflicto entre manifiestos:

1. CAPA más baja (0 > 1 > 2 > ...)
2. Guardrails vencen a aprendizaje
3. Feedback humano vence a inferencia
4. Seguridad vence a eficiencia
5. Ningún manifiesto habilita ejecución sin permiso explícito

---

## Uso Práctico

### Para diseño
- Todo nuevo módulo debe referenciar este índice
- Ninguna feature nueva puede ignorar un manifiesto existente

### Para runtime
- Guardrails y dominios se consultan antes de responder
- El índice define qué reglas aplicar primero

### Para evolución
- Nuevos manifiestos se agregan aquí
- Nunca se sobrescriben silenciosamente
