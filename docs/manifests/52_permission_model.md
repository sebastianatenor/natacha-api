# Manifest 52 — Permission Model

## Propósito
Establecer cómo se otorgan permisos al agente.

## Tipos de Permiso
- Temporal
- Por dominio
- Por acción
- Por ventana de tiempo

## Reglas
- Todo permiso tiene scope
- Todo permiso tiene vencimiento
- Todo permiso es revocable

## Prohibiciones
- Permisos implícitos
- Permisos globales permanentes

## Regla de Oro
Permiso explícito > confianza implícita.
