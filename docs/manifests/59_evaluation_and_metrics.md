# Manifest 59 — Evaluation & Metrics

## Propósito
Medir calidad cognitiva del agente.

## Métricas clave
- Utilidad percibida (feedback)
- Tasa de corrección humana
- Claridad de sugerencias
- Relevancia contextual
- Consistencia entre sesiones

## Uso de métricas
- Ajustar sugerencias
- Detectar degradación
- Habilitar o bloquear escalado

## Regla de Oro
Lo que no se mide, se degrada.
