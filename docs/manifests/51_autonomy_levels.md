# Manifest 51 — Autonomy Levels

## Propósito
Definir niveles claros y progresivos de autonomía del agente.

## Niveles
0. OFF — Sin sugerencias
1. OBSERVE — Observa y reporta
2. SUGGEST — Sugiere acciones
3. PREPARE — Prepara acciones (sin ejecutar)
4. EXECUTE — Ejecuta acciones (bloqueado por defecto)

## Reglas
- El nivel se define por dominio
- El default global es OBSERVE
- Nunca escalar sin permiso explícito

## Regla de Oro
La autonomía se gana con evidencia, no con intención.
